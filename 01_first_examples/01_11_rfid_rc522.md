# RFID Reader (RC522)

Read the unique ID (UID) and the type of an RFID card, key chain or NFC sticker with an RC522 reader. This is a basic connection example: wire the reader and read tags. Writing and cloning tags comes in a later module.

## New Concepts

- RFID and NFC
- SPI communication
- UID and card type

### RFID and NFC

An RFID tag contains a small chip and an antenna. It has no battery. The reader sends out a radio field at 13.56 MHz. The field powers the tag, and the tag answers with its data. NFC is a form of 13.56 MHz RFID. The RC522 reads the tags in this kit.

> **Warning:** The RC522 works from **3.3 V only**. Do not connect it to 5 V.

### SPI

SPI (Serial Peripheral Interface) uses four signal wires to connect the microcontroller to a device:

- **SCK**: the clock. The microcontroller sets the speed.
- **MOSI**: data from the microcontroller to the device.
- **MISO**: data from the device to the microcontroller.
- **CS** (chip select): the microcontroller pulls this wire LOW to talk to this device. On the RC522 board this pin is labelled **SDA**. It is not an I2C pin.

### UID and card type

Every tag has a **UID**, a number that identifies it. The card and key ring in this kit usually have a 4-byte UID. NFC 216 stickers have a 7-byte UID. The tag also sends a **SAK** byte that tells the reader what kind of tag it is. The `RFID` class turns this byte into a name such as "MIFARE Classic 1K".

### Wiring Diagram

**Connections:**
- RC522 `3.3V` → ESP32-S3 `3V3`
- RC522 `GND` → ESP32-S3 `GND`
- RC522 `SCK` → GPIO4
- RC522 `MOSI` → GPIO5
- RC522 `MISO` → GPIO6
- RC522 `SDA` (chip select) → GPIO7
- RC522 `RST` → GPIO8
- RC522 `IRQ` → not connected

## Code

**Files:** [`01_first_examples/code/RFID_Read.py`](./code/RFID_Read.py), [`01_first_examples/code/rfid.py`](./code/rfid.py), [`01_first_examples/code/mfrc522.py`](./code/mfrc522.py)

```python
from rfid import RFID
import time

reader = RFID(sck=4, mosi=5, miso=6, cs=7, rst=8)
print("Hold a card near the reader...")

last_uid = None
while True:
    card = reader.read()
    if card and card[0] != last_uid:
        uid, card_type = card
        print("UID:", uid, "Type:", card_type)
        last_uid = uid
    elif card is None:
        last_uid = None
    time.sleep_ms(200)
```

## Code Explanation

### Create the reader

```python
reader = RFID(sck=4, mosi=5, miso=6, cs=7, rst=8)
```
The class sets up the SPI pins and checks that the RC522 answers. It raises an error if it does not.

### Look for a tag

```python
card = reader.read()
```
`read()` returns `None` when no tag is near. When a tag is near, it returns the UID and the card type as text, for example `("04:A1:B2:C3", "MIFARE Classic 1K")`.

### Print each tag once

```python
if card and card[0] != last_uid:
    ...
    last_uid = uid
elif card is None:
    last_uid = None
```
The loop checks the reader five times per second. The variable `last_uid` stops the program from printing the same tag again while it stays near the reader. Once you remove the tag, `last_uid` is cleared and the next tap prints again.

## Key Concepts

- **SPI**: a four-wire connection between a microcontroller and a device.
- **UID**: the unique number of a tag. It identifies the tag, but anyone can read it, so it is not a password.
- **Polling**: the program asks the reader again and again whether a tag is near.
- **Reusable class**: `RFID` hides the chip driver behind one method, `read()`. The driver `mfrc522.py` is based on an open-source library and changed for the ESP32-S3.

See [RC522 RFID Reader](../reference/RC522_RFID.md) for the reader details and [Class RFID](../reference/Class_RFID.md) for the library reference.
